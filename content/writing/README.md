# Technical Writing Content

Store approved article sources in this directory as `slug.mdx`.

Each article should have:

- A title matching `src/data/writing.ts`
- An approved summary
- A real publication date
- Complete technical content
- No confidential client or architecture detail
- A corresponding public route or verified external URL

Keep the matching metadata record `published: false` until the content and URL are approved. Unpublished ideas are intentionally absent from the public website and navigation.
